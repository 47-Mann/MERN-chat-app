Group Model Explanation

File: backend/models/GroupModel.js

Purpose:
This file defines the MongoDB structure for a chat group.
The Mongoose model is named Group.

Fields:
- name is the required group name. trim removes extra whitespace at the edges.
- description is the required text describing the group.
- members is an array of User ObjectIds.
- admin stores the User ObjectId of the group administrator.

ObjectId references:
The members and admin fields use ref: "User". This allows Mongoose to populate those ids with user documents when needed.
For example:

Group.findById(id).populate("admin").populate("members");

Timestamps:
The timestamps option automatically adds createdAt and updatedAt fields.

Relationship design:
The group stores user ids instead of complete user objects. This avoids duplicating user data and keeps relationships consistent.

Current note:
The file imports bcryptjs, but it is not used by this model and can be removed during a separate cleanup.
