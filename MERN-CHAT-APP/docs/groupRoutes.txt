Group Routes Explanation

File: backend/routes/groupRoutes.js

Purpose:
This file defines API routes for creating chat groups.
The router is mounted in server.js at /api/groups.

1. Router and imports
- express creates the router.
- Group provides database operations for the Group collection.
- protect requires the request to contain a valid JWT.

2. POST /api/groups
The route is protected with the protect middleware:

router.post("/", protect, async (req, res) => { ... });

The full endpoint is POST /api/groups because server.js mounts this router at /api/groups.

3. Reading the request body
The route reads name and description from req.body.
The client should send JSON similar to:

{
  "name": "Study Group",
  "description": "A group for discussing coursework"
}

4. Creating the group
The authenticated user becomes:
- the group admin through admin: req.user._id
- the first group member through members: [req.user._id]

The protect middleware provides req.user before this code runs.

5. Populating the response
After saving, the route loads the group again and populates admin and members.
Population replaces referenced User ObjectIds with selected username and email fields.

6. Responses
- 201 means the group was created successfully.
- 400 means validation or database handling failed.

Related model:
GroupModel.js defines name, description, members, and admin.
