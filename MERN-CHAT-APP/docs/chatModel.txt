Chat Model Explanation

File: backend/models/ChatModel.js

Purpose:
This file defines the MongoDB structure for a chat message.
The Mongoose model is named Message and uses the messages collection.

Fields:
- sender stores the ObjectId of the User who sent the message. It references the User model and is required.
- content stores the message text and is required.
- group stores the ObjectId of the Group containing the message.

References:
ObjectId values keep relationships small. The ref value tells Mongoose which model can be populated later.
For example:

Message.findById(id).populate("sender").populate("group");

Timestamps:
The timestamps option automatically adds createdAt and updatedAt fields.
These fields help sort messages and track when they were created or modified.

Export:
The Message model is exported as the default export so routes or socket handlers can use it.

Current note:
The file imports bcryptjs and Model, but neither is used by the message schema. They can be removed during a separate cleanup.
